# Error Log Analyzer — Investigation Prompts & Expected Results

This document serves as the testing and evaluation guide for the **AI-Powered System Log Investigation Engine**. It pairs real-world incident prompts with the 500-line dataset in [`docs/sample_logs.log`](file:///Users/mohithkumara/Desktop/Package/ads-project/docs/sample_logs.log).

For every prompt, this document details:
1. **User Prompt**: Natural language query entered in the dashboard.
2. **DSA Routing Parameters**: Generated tool-call parameters for B+ Tree, Trie, and Heap.
3. **Expected Evidence (C++ Output)**: Exact log records and DSA performance metrics.
4. **Expected LLM Analysis & Fix**: JSON output generated by the LLM (`summary`, `root_cause`, `possible_fix`, `key_findings`).
5. **Expected DSA Visualizations**: Exact graph layout and highlighted nodes across B+ Tree, Trie, and Heap.
